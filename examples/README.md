# Synthetic worked example

Run `python examples/worked_example.py` from the public checkout. It uses only
synthetic text sources and reports; no chatbot/network/model call is made. It
creates an independent temporary Git repository, exercises installed learn.py,
then removes the temporary files. To inspect artifacts, choose a NEW directory
outside the public checkout with `--output /path/to/synthetic-demo`.

The learner has algebra and bread tracks. Both primary sources are fully mapped
and approved. The first algebra report records a heavily hinted concept answer
and a failed diagnostic, guided practice and independent fresh equation solution.
The fresh assessment explicitly resolves the diagnostic error, keeping all three
attempts in the report. Coverage advances for both, but only
the equation demonstrates understanding. The synthetic pasted report is ingested
through the installed CLI; a fenced duplicate does not change evidence or dates.
The next handoff replaces staging, preserving a downloaded return, sources and
the first durable packet. A bread recall report yields due reviews across tracks.

On the **simulated** next day, a fresh unaided equation review establishes retention
and expands its interval from 1 to 3 days. The next due date is October 18, 2026.
The example simulates an update to the next patch version using a separate copied
package; that version is a test fixture, not a published release. Preferences and every track,
report and lesson record are compared before/after. It stages prerequisite repair
as the next handoff. The output summarizes these asserted outcomes.

The report construction helpers show legacy and annotated v1 evidence shapes with actual
questions, work, hint detail, frozen rubric text and rationale. Unit tests add
malformed/conflicting reports, disputed assessments, early/failed reviews,
mailbox path protection, transformation approvals and update failures.

The inherited algebra teaching preference now requests detailed mechanisms and
worked examples before practice; bread demonstrates a retained explicit short-style
override. This offline library example does not perform network updates or Git
publication. Those are agent workflow steps; focused tests exercise trusted-update
activation and private backup outcomes with synthetic repositories and mocked APIs.
