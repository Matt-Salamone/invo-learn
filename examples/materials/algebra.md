# Synthetic algebra notes

## Inverse operations
An equation states equality. Adding or subtracting the same quantity on both
sides preserves equality. Multiplying or dividing both sides by the same nonzero
quantity also preserves equality. An inverse operation undoes an operation.

## Linear equations
For ax + b = c with a nonzero, subtract b from both sides and divide by a.
For example, 3x + 2 = 14 becomes 3x = 12 and x = 4. Check by substitution.
Practice should use fresh coefficients, including negatives when ready.
